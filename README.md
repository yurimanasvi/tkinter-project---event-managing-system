# Eventify – Event Management System

## About the Project
Eventify is a desktop-based Event Management System developed using Python and CustomTkinter. It provides an interactive interface to manage events, guests, and event-related information.

The application uses a modern black and gold theme with simple navigation.

## Features
- **Dashboard:** Displays event statistics and upcoming events.
- **Event Management:** Add, edit, delete, and search events.
- **Guest Management:** Add, search, delete guests, and mark attendance.
- **Analytics:** Displays attendance and budget summaries.
- **User-Friendly Interface:** Simple and interactive navigation.

## Technologies Used
- Python
- CustomTkinter
- Tkinter

## Project Objective
The main objective of Eventify is to demonstrate how Python GUI programming can be used to develop an interactive application for managing events and guest information.

## Data Handling
This project is frontend-only and uses sample data stored temporarily in Python lists. It does not use a database, so changes are not permanently saved.
